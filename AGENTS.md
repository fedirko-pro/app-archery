# AGENTS.md

Guidance for AI agents working in this repository.

## Project

**Sokil** — archery training companion (Next.js 15 + NestJS 11, pnpm monorepo).

- `apps/web` — Next.js 15 frontend (`@sokil/web`), port 3001
- `apps/api` — NestJS 11 backend (`@sokil/api`), port 3000
- `packages/shared-types` — shared TypeScript types
- `packages/shared-configs` — shared ESLint / TS config
- `deploy/` — production Docker Compose (Traefik)

Node `>=22.12.0`, pnpm `>=9`. Never use `npm`/`yarn`.

## Commands

| Task       | Command                                                        |
| ---------- | -------------------------------------------------------------- |
| Dev (both) | `pnpm dev`                                                     |
| Dev web    | `pnpm dev:web`                                                 |
| Dev api    | `pnpm dev:api`                                                 |
| Build      | `pnpm build`                                                   |
| Lint       | `pnpm lint` (Biome; web also uses `biome check src`)           |
| Typecheck  | `pnpm typecheck` (web + api `tsc --noEmit`)                    |
| Test       | `pnpm test` / `pnpm test:run` (Vitest)                         |

Per-package equivalent: `pnpm --filter @sokil/web <script>` /
`pnpm --filter @sokil/api <script>`.

## Environments

| Environment | Frontend                    | API                             |
| ----------- | --------------------------- | ------------------------------- |
| Live        | https://sokil.app           | (live API host)                 |
| Test        | https://archery.fedirko.pro | https://api-archery.fedirko.pro |

- `NEXT_PUBLIC_SITE_MODE` (`test` | `prod`) is baked into the web image at build
  time. It only controls the header "test" badge and GA gating — not the domain.
- Live and test frontends are **separate origins**, so PWA/service-worker state,
  installed-app identity, and `localStorage` do not carry between them.
- `NEXT_PUBLIC_*` env vars are inlined at build time; changing them requires a
  frontend rebuild (see `deploy/deploy.sh`).

## PWA notes

- Service worker is generated by `@serwist/next` (`next.config.ts` →
  `src/app/sw.ts` → `public/sw.js`). It is auto-registered via the injected
  `sw-entry`; do **not** add a manual `navigator.serviceWorker.register` or a
  `SerwistProvider` (would double-register).
- Install prompt UI: `src/hooks/usePwaInstall.ts` (Android `beforeinstallprompt`)
  and `src/components/AppStatusBar/AppStatusBar.tsx` (also shows the iOS
  "Add to Home Screen" tip). `src/components/InstallPrompt/` is currently
  unused/legacy.
- `beforeinstallprompt` must be captured at module scope (see
  `ensureBeforeInstallListener()` in `usePwaInstall.ts`); it can fire before
  React mounts on repeat visits.
- Install-prompt dismissal cooldowns are stored in `localStorage` and set to
  **1 day** (`PWA_DISMISS_DAYS`, `IOS_A2HS_DISMISS_DAYS`).
- The manifest is `apps/web/public/manifest.webmanifest` (`id`/`start_url` are
  `"/"`, which the middleware redirects to `/{lang}/tournaments`).

## Conventions

- Commits use Conventional Commits (enforced by commitlint), e.g.
  `fix(web): ...`, `feat(api): ...`.
- Lint/format via Biome (`biome check`), SCSS via Prettier. Pre-commit runs
  lint-staged; pre-push runs typecheck + lint + build.
- No code comments unless asked.
- Do not commit `.env` (secrets live in `/srv/test-archery/.env` on the VPS).

## Deployment

See `DEPLOYMENT.md` (Hostinger VPS + Traefik). Deploy from `origin/main`
(live) / `origin/dev` (test): `bash deploy/deploy.sh` on the VPS. Builds one
service at a time to avoid OOM on the 4 GB VPS.
